Telegram-бот для создания шаблонов тренировок, записи выполненных тренировок и отслеживания параметров тела.

Основной функционал:

📋 Шаблоны тренировок

Для каждого упражнения можно указать:

- Добавление шаблона для тренировок (с указанием названия шаблона, количества упражнений, количества подходов и повторений, начального веса и/или резинки)
- Просмотр списка шаблонов с пагинацией (по 3 на страницу)
- Просмотр конкретного шаблона
- Удаление шаблона с подтверждением

💪Тренировки

- Добавление тренировки по готовому шаблону
- Просмотр истории выполненных тренировок

📏 Параметры тела

- Запись параметров (с указанием текущего веса в кг, а также параметров в свободной форме)
- Просмотр истории записей с пагинацией (по 3 на страницу)
- Просмотр конкретной записи с параметрами
- Удаление записи с подтверждением

🔄 Навигация

- Встроенная пагинация для списков шаблонов/параметров/тренировок (кнопки "Вперёд" / "Назад")

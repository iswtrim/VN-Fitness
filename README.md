# 🏋️ Telegram-бот для тренировок (Workout Tracker)

Telegram-бот для создания шаблонов тренировок, записи выполненных упражнений и отслеживания параметров тела. Проект написан на асинхронном фреймворке `aiogram 3` с использованием базы данных PostgreSQL.

## ✨ Основной функционал

### 📋 Шаблоны тренировок
- Создание шаблона с пошаговым вводом (название, количество упражнений, подходов, повторений, вес/резинка).
- Просмотр списка шаблонов с пагинацией (по 3 на страницу).
- Просмотр деталей конкретного шаблона.
- Удаление шаблона с подтверждением.

### 💪 Тренировки
- Запись выполненной тренировки на основе готового шаблона.
- Просмотр истории выполненных тренировок.

### 📏 Параметры тела
- Запись текущего веса (кг) и дополнительных параметров в свободной форме.
- Просмотр истории замеров с пагинацией.
- Удаление записи с подтверждением.

### 🔄 Навигация
- Встроенная пагинация для всех списков (кнопки «Вперёд» / «Назад»).
- Использование `FSM` (Машины состояний) для пошагового ввода данных.

## 🛠 Стек технологий
- **Python 3.10+**
- **aiogram 3.x** — асинхронный фреймворк для Telegram-ботов
- **PostgreSQL** — реляционная база данных
- **asyncpg** / **SQLAlchemy** — асинхронная работа с БД
- **python-dotenv** — управление переменными окружения

## 🔒 Безопасность
В проекте реализован `AccessMiddleware`, который перехватывает все входящие сообщения и колбэки. 
Доступ к функционалу бота имеют только пользователи, чьи Telegram ID указаны в переменной `ALLOWED_USER_IDS`. Для всех остальных бот выводит сообщение «⛔ Доступ запрещён».
